# /status

Quick pass/fail compliance health check for the current project. No fix prompts.

Dispatches to the `status` skill.

**Usage:**
- `/status` — check both Android and iOS
- `/status android` — Android only
- `/status ios` — iOS only

Pass all arguments through to the skill unchanged.
